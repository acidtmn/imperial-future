== Назначение ==

В 1.1.3 закрыты превью комментариев и голосование для недоступных записей,
исправлены загруженные аватары и сохранение Markdown-кода с тильдами.
Для управления подписками и почтовыми уведомлениями из кабинета требуется
подтверждение адреса по одноразовой ссылке. Само подтверждение email не
подписывает на дайджест; выбор рассылок остаётся за читателем.

Тема личного сайта с лентой публикаций, светлым и тёмным оформлением,
кабинетом, закладками, оценками, комментариями Markdown и контактной формой.
Тема предназначена для установки на собственный сайт. Публикация в каталоге
WordPress.org не предполагается. Дополнительный companion-плагин не нужен.

== Требования и установка ==

Проверенная конфигурация - WordPress 7.1.3 и PHP 8.3. На сервере нужны обычные
расширения WordPress, а также mbstring, DOM и XML для библиотек Markdown.
Используй HTTPS и сделай резервную копию файлов и базы перед обновлением.

1. Открой Внешний вид -> Темы -> Добавить тему -> Загрузить тему.
2. Выбери imperial-future-1.1.3.zip, установи и активируй Imperial Future.
3. Открой Внешний вид -> Настроить -> Imperial Future: настройки темы.
4. Укажи собственные контакты, ссылки на социальные сети и параметры сайта.
   Демонстрационные значения не являются реальными контактами автора.
5. Настрой меню и виджеты через стандартные разделы Внешний вид.

ZIP уже содержит vendor и собранные assets/dist. Composer, Node.js, Vite
и Docker на сервере сайта для установки темы не нужны.
При активации демо-контент не импортируется и существующие статьи не удаляются.
Отсутствующая страница кабинета создаётся при явном импорте демо.

== Настройки оформления ==

Customizer содержит палитру, логотипы, шрифты, блоки главной, слайдер,
эффекты, функции публикаций, контакты, поиск, кабинет, OAuth, рекламу,
счётчики и SEO. Настройки сохраняются для этой темы.
Для обычных страниц контактов и кабинета используются page-contacts.php
и page-account.php; демоимпорт создаёт необходимые страницы автоматически.

Шрифты Inter, Oranienbaum, Forum, Prata, PT Sans и IBM Plex Sans включены
локально в assets/dist/media. Загрузка шрифтов с Google Fonts не требуется.
Иконки интерфейса собраны из Lucide; автоматическая загрузка Font Awesome
в редакторе комментариев отключена.

В комплект включена собственная бренд-монограмма «И» в SVG для светлого
и тёмного оформления, PNG-значки сайта, favicon и apple-touch-icon
в assets/images/brand. Логотипы используются по умолчанию, если свои изображения
не выбраны в Customizer; значок сайта WordPress имеет приоритет над запасным.
Для публикации ссылки есть растровое изображение assets/images/og-imperial.png:
оно используется, если нет подходящей обложки статьи или своей картинки SEO.

Стартовый набор содержит семь редакционных иллюстраций,
подготовленных для темы, в assets/images/editorial: hero, цифровая мастерская,
домашняя лаборатория, независимый архив, ключи доступа, спокойный телеграф
и читаемый интерфейс. Файлы поставляются в WebP; внешние фотостоки и скачивание
изображений при открытии сайта не требуются.

== Явный импорт демо ==

Открой Инструменты -> Демо Imperial Future и нажми Добавить демо-контент
только когда действительно хочешь добавить примеры на этот сайт.
Импорт доступен администратору и защищён проверкой прав и nonce.
Он добавляет рубрики, публикации, изображения, страницы и примеры комментариев.
Имеющиеся материалы не удаляются; существующие страницы с теми же адресами
переиспользуются. Меню назначаются только в свободные области, виджеты
добавляются только в пустые области. Демо-меню с именем «Имперская навигация»
может быть дополнено отсутствующими пунктами.
Повторный запуск переиспользует найденные демо-объекты, а не очищает сайт.
Импорт не является транзакцией и не имеет кнопки полного отката:
для возврата к прежнему состоянию используй заранее сделанную резервную копию.
Стартовые иллюстрации включены в тему локально, скачивание внешних фотографий
не нужно. Демоимпорт добавляет материалы отдельно от установки оформления.

== Вход и регистрация ==

Показ кабинета и формы входа управляется разделом Кабинет, вход и поиск.
Создание новых аккаунтов отдельно разрешается в Настройки -> Общие ->
Членство -> Любой может зарегистрироваться. Для новых пользователей выбирай
роль Подписчик. Выключенная регистрация не мешает входу существующих аккаунтов.
Вход через VK и Яндекс не обходит запрет регистрации новых пользователей.

== Комментарии ==

EasyMDE предоставляет редактор Markdown и предпросмотр. Серверный рендеринг
и предпросмотр используют League CommonMark. Поддерживаются выделение,
ссылки, списки, цитаты, строчный код и блоки кода с тройными обратными кавычками.
Исполняемый HTML и опасные ссылки не допускаются. Старые HTML-комментарии
приводятся к Markdown через league/html-to-markdown.
Доступность комментариев и их модерация настраиваются в Настройки -> Обсуждение
и отдельно у публикаций. Правила модерации WordPress продолжают действовать.

== SEO и карта сайта ==

В разделе SEO, OpenGraph и Яндекс можно включить метаданные темы и настроить
описание, изображение для публикации ссылки, суффикс заголовка и индексацию.
При активном Yoast SEO, Rank Math, All in One SEO (AIOSEO) или SEOPress
тема автоматически прекращает свой вывод SEO-метаданных и Schema,
чтобы не дублировать соответствующий вывод плагина.
Защитный noindex для кабинета, страниц с паролем и 404 остаётся независимо
от этого переключателя. Счётчик Яндекс Метрики включается своим параметром.
Отдельный генератор sitemap в тему не встроен: используется карта сайта ядра
WordPress по /wp-sitemap.xml либо карта активного SEO-плагина.
Тема исключает страницы с шаблоном кабинета из карты страниц ядра.

== Почта и внешние интеграции ==

Контактная форма и почтовые уведомления используют wp_mail(). Тема не содержит
SMTP-транспорт и не поставляет SMTP-пароли. Настрой реальную доставку почты
на сервере или через отдельный SMTP-плагин. Укажи собственные адрес получателя
и From email, проверь доставку, SPF/DKIM/DMARC и письма восстановления пароля.
Сам по себе успешный вызов wp_mail() не доказывает доставку адресату.

== Еженедельный дайджест ==

Переключатель дайджеста находится в Customizer -> Функции публикаций.
Публичная форма подписки отправляет письмо с подтверждением на 24 часа.
Выпуски получают только подтверждённые подписчики; письмо содержит отписку.
Планировщик темы назначает еженедельный выпуск на понедельник, 09:00
по часовому поясу из Настройки -> Общие. Выпуск содержит публичные статьи
без пароля за последние семь дней. Без статей или получателей письмо не уходит.
Отправка выполняется партиями до десяти адресов через wp_mail().
Задания выполняет WP-Cron, поэтому при редких посещениях запуск может задержаться.
Для регулярного запуска обеспечь вызов WP-Cron на сервере; тема сама не создаёт
системный cron. При выключении дайджеста задания темы удаляются.
Реальная доставка через внешний почтовый сервис остаётся отдельной проверкой.

== OAuth и другие интеграции ==

Для VK и Яндекс создай собственные OAuth-приложения, укажи Client ID и Secret
в разделе Интеграции. Адрес возврата - главная страница твоего сайта с
?imperial_oauth=vk или ?imperial_oauth=yandex соответственно.
Client ID «#» служит демонстрационной кнопкой и не выполняет реальную авторизацию.
OAuth-ключи сохраняются в настройках базы сайта; не включай их в архив темы.
Перед использованием проверь реальную доставку и полный OAuth-вход на своём
домене. Аналитика и рекламные вставки требуют отдельных настроек;
учти правила обработки данных посетителей. Встроенной капче внешние ключи не нужны.

== Исходники, лицензии и сборка ZIP ==

В пакете сохранены PHP, src/js, src/scss, конфигурация Vite, theme.json,
package.json, package-lock.json, composer.json, composer.lock, языковые файлы,
изображения, готовые ресурсы, лицензии и screenshot.png.
node_modules, тестовые снимки, тесты, output, секреты и dev Docker не включаются.
Сторонние компоненты сохраняют собственные лицензии. Собственный код темы
имеет GPL-2.0-or-later, но весь bundle не объявляется GPL-compatible:
GSAP распространяется на условиях отдельной Standard License.

Из корня проекта после готовности vendor, переводов и production-ресурсов
(для ZIP нужен PowerShell 7.2 или новее):

docker compose exec -T node npm ci
docker compose exec -T node npm run build
docker compose exec -T node node tools/collect-licenses.mjs
pwsh -NoProfile -File scripts/package-theme.ps1

Сборщик лицензий копирует полные тексты из установленного node_modules,
проверяет версии по lock-файлу и сохраняет реестр licenses/index.json.
Недостающие upstream-тексты GSAP и Typo.js закреплены в licenses/supplemental.
При обновлении этих зависимостей нужно проверить и обновить их условия.
Composer-зависимости уже должны быть установлены по composer.lock без dev-пакетов.

package-theme.ps1 проверяет обязательные файлы, ссылки manifest, Composer
и реестр лицензий, затем пишет output/imperial-future-1.1.3.zip напрямую
из theme с единственным верхним каталогом imperial-future.
Порядок файлов, время записей и права фиксированы; используется ZIP без сжатия
для воспроизводимости байтов независимо от версии алгоритма Deflate.
Одинаковые исходные файлы в одной среде PowerShell/.NET дают одинаковый SHA-256.
Во время упаковки не меняй
тему и не запускай сборку параллельно. Скрипт не изменяет исходники, не копирует
checkout и не устанавливает зависимости. Готовый архив не содержит базы сайта.
