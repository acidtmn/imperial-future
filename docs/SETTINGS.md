# Все настройки Imperial Future 1.1.2

Путь: **Внешний вид -> Настроить -> Imperial Future: настройки темы**. Ниже перечислены все 114 зарегистрированных полей в 13 разделах. Это исходные значения темы, не настройки или секреты конкретного сайта. Импорт демо может изменить часть оформления.

Справочник сформирован из определений WordPress Customizer, без чтения сохранённых значений. «Включено/выключено» относится к переключателю; «пусто» означает отсутствие своего значения. Изображения выбираются из медиатеки и хранятся как ID. Текст кнопки и ссылка - разные поля. После изменения нажми «Опубликовать» в Customizer.

Практические пояснения, подключение внешних сервисов и стандартные настройки WordPress: [установка](INSTALLATION.md), [возможности](FEATURES.md).

## Стандартные настройки WordPress

- **Название, краткое описание, язык, часовой пояс, email администратора:** Настройки -> Общие. Для русских дат выбери ru_RU и свой часовой пояс.
- **Регистрация:** Настройки -> Общие -> Членство. Роль нового пользователя - Подписчик. Переключатель кабинета сам по себе регистрацию не разрешает.
- **Значок сайта:** стандартный «Значок сайта» WordPress имеет приоритет над favicon темы. Рекомендуется квадратное изображение 512x512.
- **Обсуждение:** комментарии, модерация, вложенность и уведомления администратору задаются в Настройки -> Обсуждение, а также у каждой записи.
- **Главная и индексация:** Настройки -> Чтение. Перед публичным запуском отключи запрет индексации поисковиками; на тестовом сайте оставь его включённым.
- **URL:** Настройки -> Постоянные ссылки. Установи желаемую структуру до публикации, старые адреса меняй только с редиректами.
- **Меню и виджеты:** Внешний вид -> Меню / Виджеты. Доступны два меню и три области, перечисленные в справочнике возможностей.
- **Избранное hero:** закрепи нужные записи штатным флажком WordPress. Без закреплённых слайдер использует свежие публикации.

## Что не настраивается отдельным полем

SMTP-host/порт/пароль, ручной crop аватара, собственная схема CAPTCHA, время отправки дайджеста, отдельный выключатель каждого стандартного Gutenberg-блока, число символов старта поиска и произвольные новые позиции виджетов не имеют отдельных полей Customizer. SMTP подключается сервером/плагином; остальные изменения требуют разработки. Не все элементы страницы являются отдельными настройками.
